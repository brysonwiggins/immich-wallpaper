# App icon

Source artwork for the launcher icon. The app's icon resources are in `app/src/main/res/` (`mipmap-*` and
`drawable/ic_launcher_*.xml`). The notification icon, `drawable/ic_stat_wallpaper.xml`, is based on the
monochrome layer.

| File | Use |
|---|---|
| `icon-rounded.svg`, `icon-rounded-1024.png` | Rounded-square master |
| `icon-round.svg`, `icon-round-1024.png` | Round master |
| `icon-fullbleed.svg` | Full-bleed master, for adaptive icons |
| `playstore-512.png` | Google Play listing icon (Play applies its own mask) |

Palette: background `#151A33`, frames `#EDEAFF`, cards `#2E3A70` and `#7B6CF6`, sun `#FFD27A`.
